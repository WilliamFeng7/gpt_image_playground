# GPT Image Playground for macOS

适用于 Apple 芯片 Mac 的图像工作台。支持文生图、参考图编辑、画廊和 Agent 对话，兼容 OpenAI、Gemini、Grok 等图像 API。

## 下载与使用

1. 在 [GitHub Releases](https://github.com/WilliamFeng7/gpt_image_playground/releases/latest) 下载 ARM64 `.dmg`。需要 macOS 14 或更新版本。
2. 打开磁盘镜像，把 **GPT Image Playground** 拖到「应用程序」。
3. 在「设置 → API 配置」选择供应商并填写 API Key。图片和历史记录保存在本机。
